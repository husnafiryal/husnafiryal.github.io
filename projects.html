Academic Capstone

Millimeter Wave FMCW Radar River Telemetry System

Problem

Manual river monitoring is hazardous, labor-intensive, and fails to provide automated real-time tracking of water levels and flow velocity during severe weather events.

Outcome

Designed a non-contact FMCW radar system that accurately estimates surface height and water velocity under diverse environmental conditions.

Tech Stack
FMCW Radar Signal Processing Python Linux IoT Telemetry Data Logging Fourier Transform
Solution

Deployed a millimeter-wave FMCW radar system running Python scripts on a local unit to extract frequency beat signals. Applied Fast Fourier Transform (FFT) and spectral analysis to calculate distance (surface height) and Doppler frequency shift (water flow velocity).

Key Highlights
  • Calculated non-contact water distance telemetry using high-resolution radar reflection frequencies.
  • Derived surface velocity measurements from phase change rates using the Doppler effect.
  • Configured local SQLite databases for continuous local logging and telemetry storage.

DevOps Flagship

Centralized GitLab CI/CD Pipeline for Kubernetes Deployment

Problem

Manual deployment to Kubernetes is prone to inconsistency, difficult to replicate, and risky because pipeline configurations, credentials, and manifests can be scattered across multiple locations.

Outcome

The pipeline successfully executed on the alpha branch with both build and deploy stages passing. The application was deployed to a Kubernetes namespace and is accessible via the public domain una-cicd.apps.k3s.zauqilab.com. Code updates were successfully processed by the pipeline and reflected in the browser, validating the deployment automation workflow.

Tech Stack
GitLab CI/CD Docker GitLab Container Registry Kubernetes K3s kubectl envsubst Kubernetes Secret ImagePullSecret Ingress/Traefik Reusable Pipeline DevOps Automation
Solution

I built a reusable CI/CD pipeline using two separate repositories: one for the application and a dedicated repository for the centralized/general pipeline. The application repository uses the include feature to call the main pipeline, preventing build and deploy logic from being written repeatedly in every project.

My Contributions
  • Designed the two-repository structure separating application code from centralized pipeline configurations.
  • Wrote the multi-stage Dockerfile and Kubernetes manifests for deployment.
  • Configured and optimized the GitLab CI/CD build and deploy pipeline.
  • Established secure access using GitLab CI/CD Variables and Kubernetes ImagePullSecrets.
  • Corrected the Traefik Ingress configuration to successfully expose the application via public domain.
What I Learned
  • Decoupling pipeline templates from codebase files for improved reusability.
  • Implementing secure secret management patterns in automated deployment workflows.
  • Orchestrating automated rollouts to Kubernetes environments.
